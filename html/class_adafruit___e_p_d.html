Start fast mode: clean the panel to white with a full refresh, load the fast waveform and allocate the lag history. Mono mode only, and a BUSY pin is required.

Parameters

Returns

◆ fastClean()

void Adafruit_EPD::fastClean ( uint8_t  frames = 8,
bool  full = false 
)

Clean the panel without breaking DC balance: drive the image back to white, then run a balanced wipe (frames to black, frames to white). With full = true an OTP full refresh runs before the wipe. The screen is left white; call displayFast() (or fastSettle()) to show the buffer again.

Parameters
frameswipe updates in each direction. Use 0 for no wipe.
fullif true, also run a full OTP refresh
