Detailed Description

Fast lag-drive updates for monochrome e-paper.

Each displayFast() sends the new frame to the "new" RAM plane and the frame from lag updates ago to the "old" plane, then runs a short balanced waveform in display mode 2. Only pixels that differ are driven, and every change is driven for lag updates, the same number of frames toward black as toward white, so the drive stays DC balanced.

Only the bounding box of changed bytes is written, and the BUSY wait for an update happens at the start of the next call, so drawing the next frame overlaps the panel update.
